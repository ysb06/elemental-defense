# Elemental Defense

물·불·흙 세 원소의 상성과 지형을 활용해 본영을 지키는 3D 전략 디펜스 게임입니다.

## 게임 플레이

### [▶ 브라우저에서 Elemental Defense 플레이하기](https://ysb06.github.io/elemental-defense/)

공개 WebGL 빌드는 위 링크에서 제공될 예정입니다. 데스크톱 브라우저와 키보드·마우스 사용을 권장합니다.

## 게임 소개

- 물·불·흙 속성 타워를 전략적으로 배치해 몰려오는 적을 막습니다.
- `물 → 불 → 흙 → 물`로 이어지는 원소 상성과 속성 지형을 활용할 수 있습니다.
- 타워는 적을 자동으로 탐색하고 공격하며, 필요할 때 이동하거나 철거할 수 있습니다.
- 스킬 게이지가 충전되면 광역 공격 스킬을 사용할 수 있습니다.
- 10개의 스테이지에서 각각 10개의 웨이브에 도전합니다.
- 모든 웨이브를 막으면 승리하며, 본영이 파괴되거나 제한 시간이 끝나면 패배합니다.

## 플레이 방법

1. 메인 화면에서 `START`를 눌러 로비로 이동합니다.
2. 해금된 스테이지를 선택하거나 로비에서 바로 전투를 시작합니다.
3. 물·불·흙 타워 중 하나를 선택하고 배치 가능한 타일을 클릭합니다.
4. 원소 상성과 지형을 고려해 타워를 이동하고 스킬을 사용합니다.
5. 본영을 지키며 10개의 웨이브를 모두 막으세요.

## 조작

| 기능 | 조작 |
| --- | --- |
| UI·타워·타일 선택 / 배치 | 마우스 왼쪽 버튼 |
| 카메라 이동 | `WASD` 또는 방향키 |
| 화면 이동 | 마우스 가운데 버튼 드래그 |
| 확대·축소 | 마우스 휠 |
| 카메라 초기화 | `R` |
| 배치·이동 취소 | `Esc` |

## 디버그 모드

로비의 설정 버튼에서 진입합니다. 최근 플레이 결과에 따른 AI 기반 난이도 조절과 `Loop` 변경에 따른 맵 패턴 차이를 확인할 수 있습니다.

- **난이도 비교:** 특정 스테이지를 플레이한 뒤 `Defeat / 0초 / HQ 0/100 / 처치 0`을 `Inject`하고 같은 스테이지를 다시 플레이합니다. 10회 주입하면 AI 난이도 배율이 최저값 `1.0`이 되며, 비교 후 `Clear`로 해제합니다.
- **맵 비교:** 특정 스테이지를 플레이한 뒤 `maxStageProgress`는 유지하고 `Loop`를 현재 값보다 `1` 높여 `Apply`한 다음, 같은 스테이지를 다시 플레이합니다. 비교 후 원래 `Loop`로 되돌립니다.
